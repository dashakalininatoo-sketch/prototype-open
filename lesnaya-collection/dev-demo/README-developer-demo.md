# Motion demo · экран планировок

Открывать через HTTP: `python3 -m http.server 8773` и затем `http://127.0.0.1:8773/developer-demo.html`.

## Что проверять

- Карточки планировок имеют размер 335 × 280 px и gap 8 px.
- Во время свайпа масштаб каждой карточки непрерывно следует за её положением: от 94% вне центра до 100% в активной позиции. Используется вариант 1 — `smoothstep` по всей траектории.
- После snap обновляются заголовок, counter и три оффера; блок офферов входит с translateX ±12 px при прозрачности 100%.
- Масштаб привязан к прогрессу скролла, поэтому отдельного таймера на 280 мс нет: `p = 1 − min(1, |index − scrollLeft / 343|)`, `scale = 0.94 + 0.06 × p²(3 − 2p)`. Блок офферов сдвигается на ±12 px за 300 мс с `cubic-bezier(.4, 0, .2, 1)` после смены активной планировки.
- Кнопки «Назад», «Вперёд» и «Повторить» предназначены для демонстрации смены планировок.
- Иконка `Icons/Action/24/More` у каждого оффера — статичная заглушка: она не нажимается, не меняет состояние и не открывает snackbar. Сердечко переключает избранное.
- В production при `prefers-reduced-motion` оставить мгновенную смену состояния без transform-анимаций.

Демка не содержит переходов на другие экраны и не заменяет runtime-прототип.
