# Экран планировок · ЖК «Лесная Коллекция»

Отдельный прототип одного экрана. Открывать через локальный HTTP-сервер, например из родительской папки: `python3 -m http.server 8772 --bind 127.0.0.1`.

- Горизонтальная карусель: карточки 335×280 px, шаг 343 px, промежуток 8 px, snap по одной планировке.
- Неактивная карточка: 94%. Масштаб непрерывно следует за горизонтальным скроллом на всём пути и достигает 100% в активной позиции по `smoothstep`.
- При смене планировки обновляются площадь, количество и офферы. Список офферов сдвигается на ±12 px по направлению свайпа за 300 мс с `cubic-bezier(.4, 0, .2, 1)`; прозрачность остаётся 100%.
- Многоточие у каждого оффера — статичная заглушка без действия и смены состояния. Сердечко переключает избранное отдельно у каждого оффера.
- Многоточие и неактивное сердце используют `Control/Main/Primary/Default` `#006CFD`; активное сердце — `Control/Negative/Primary/Default` `#DB1F36`.
- Данные: шесть реальных групп и 27 офферов из исходного dataset. Изображения и иконки скопированы локально.
- Стрелка, 3D, CTA и «Посмотреть» показаны только визуально; переходов из экрана нет.
