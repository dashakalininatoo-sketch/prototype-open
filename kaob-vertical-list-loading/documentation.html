Живая анимация

Как смотреть

Сначала показана загрузка квартир. «Квартиры» — слева; при переключении на «Планировки» загрузка повторяется. Фильтры работают; переходы из карточки ЖК отключены. В продукте скелетон показывается на время запроса квартир.

Это фрагмент рабочего прототипаВ окне запущен рабочий прототип. Автопрокрутка и искусственная пауза нужны только для воспроизведения демки; это не требования к продукту.
